## 💡 为什么需要专用的申论研习台？（对比通用 ChatGPT / Claude 对话框）

通用大模型聊天窗口的底层逻辑是**“单次消费型线性问答”**，考生复制一段材料和作答丢给 AI，AI 吐出 2000 字文字墙。窗口一关，知识沉睡，考生的思维短板依然没有得到任何根治。

申论备考的高分逻辑必须是**“考场物理实战 + 采分点像素级色谱穿透 + 个人积累资产复利 + 跨试卷认知病灶手术”**。

| 评估维度 | 在通用 AI 窗口（Claude / GPT / 各种套壳站）提问 | 在【申论智能研习台】专用系统研习 |
| :--- | :--- | :--- |
| **作答媒介** | 敲键盘打字，破坏考场手感与时间感 | **坚持实体方格纸手写作答后敲入**，系统充当“认知手术台” |
| **审题阅读** | 界面只有输入框，无法对照材料 | **题干与给定资料全文展开阅览**，支持直接上传 PDF 讲义秒级提取文字 |
| **批改呈现** | 2000字黑白纯文字墙，上下翻滚脑补对应 | **全真多维色谱穿透**（原词绿/大词黄/漏点红/臆造紫/流水账灰/抄袭黄闪烁） |
| **给分归因** | 黑盒给一个分数，不知道为什么扣 | **四维量化赋分表 + 考官多视角判语 + 逐句扣分归因穿透清单** |
| **错误追踪** | 对话关闭即失忆，无法知道历史扣分规律 | **跨试卷认知病灶图谱**，动态统计抄袭率、口语率，**下次作答置顶自反性警报** |
| **记忆积累** | AI 示范文辞藻华丽，考生考场根本写不出 | **限制性一类文重塑 (MAR)**：强约束优先融入考生自己背熟的素材，**100% 考场可复现** |
| **知识沉淀** | 批改完就结束，没有后续动作 | **扣分点一键存为【避坑错题卡】+ 范文【划词即入库】+ SM-2 艾宾浩斯复习流** |
| **即时纠偏** | 告诉你大白话扣分，没有即刻训练 | **现场生成 3 分钟针对性微练习**，当场敲入政务大词，系统秒判切除病灶 |
| **数据隐私** | 考生个人作答与笔记上传至第三方服务器 | **100% 留存在浏览器本地 (IndexedDB)**，服务端零留存、零数据库，**严格 BYOK** |

## 🚀 快速上手 (Quick Start)

### 方式 1：Windows 一键快速启动（推荐）
直接在项目根目录下双击运行：
👉 **`start.bat`**
* 脚本将自动启动后台无状态算力服务，并自动调起浏览器访问：`http://127.0.0.1:8789/`。

### 方式 2：命令行手动启动
```bash
# 1. 安装轻量依赖
pip install -r server/requirements.txt

# 2. 启动服务
python server/src/main.py
```
打开浏览器访问：`http://127.0.0.1:8789/` 即可。

### 自动化单元测试验证 (TDD)
```bash
cd server
pytest
```
* 执行 9 项全覆盖单元测试（包括 Skill 挂载、色谱坐标回填、抄袭检测、记忆审计、微练习秒判、API 端点）。

## 📖 核心功能操作指南

### 1. ✏️ 纸面手写作答与全真色谱批改
* **选择试卷材料**：在下拉菜单中直接选择官方预置真题（如 2026 年国考、2025 江苏省考），或选择您自行上传的私有 PDF 讲义材料；
* **阅读与审题**：材料阅读面板会自动将试卷全文按自然段落连贯排版展开，清晰标注段落字数；
* **敲入作答**：在实体纸写完后录入正文，系统实时核算字数并前置提示书名号或字数红线；
* **点击批改**：系统调用 DeepSeek-V3 实时在线推理（约 3~6 秒），右侧即时呈现字符级多维色谱、四维量化得分表、考官第一眼判语与逐句扣分归因。

### 2. 📖 个人申论记忆库 (基于 Anki SM-2 算法)
* 预置生态文明、基层治理、新质生产力核心金句与对策模板；
* 点击卡片即可**翻面查看背诵内容**，支持【忘词 (10m) / 良好 (1d) / 秒答 (4d)】艾宾浩斯流转；
* 每次批改时，系统本地检索引擎（Mini-RAG）会自动根据题目匹配您背过的卡片，并**逆向审计作答激活率**！

### 3. 🏛️ 官方真题与私有知识库
* **公共真题库**：服务端只读分发，秒级加载，不占浏览器配额；
* **私有材料上传**：支持直接上传本地 `.pdf`（带文字图层）、`.md`、`.txt`；
* **划词即入库（Click-to-Card）**：在阅读器中用鼠标选中任意 4 字以上金句，即可弹出浮动气泡一键加入【个人申论记忆库】；
* **试卷联动**：上传的私有材料会自动同步到作答页面的下拉菜单中，可直接作为考试材料进行针对性练习！

### 4. 🧬 跨试卷认知病灶图谱
* 每次批改后，系统自动萃取材料过度抄袭（超 20% 红线）、口语大白话、骨架残缺等缺陷，存入本地 `dossier` 数据库；
* 动态统计历史犯错率；连续触碰自动锁定为**【一级顽固病灶】**；
* **自反性闭环**：当下一次进入作答页面时，作答框上方自动弹出置顶警报条，提醒您本次注意纠偏。

### 5. 🛠️ Skill 提炼工坊
* 允许上传您私有的名师讲义或笔记；
* AI 自动提取其阅卷心智、量化评分表、扣分雷区与示范模板，在本地生成专属批改专家，直接挂载到作答页下拉框中使用。

## 🔒 隐私安全与数据保护架构

1. **绝对本地留存（Zero-Knowledge / Zero-Retention）**：
   - 所有作答记录、批改报告、记忆卡片、私有知识库文档 100% 存储于当前浏览器的 **IndexedDB** 数据库中；
   - 服务端仅作为纯算力中转，不设数据库，不存任何个人答卷，处理完毕内存即焚。
2. **纯客户端自持密钥 (Strict BYOK)**：
   - 用户在网页端【⚙️ 模型配置】输入 API Key，保存在本地浏览器 `localStorage`；
   - 默认支持 **DeepSeek-V3**（`https://api.deepseek.com/v1`），亦可无缝切换火山方舟 Ark、Qwen、OpenAI 等任意兼容端点。
3. **温和主动防丢**：
   - 首页常驻本地隐私沙箱状态；
   - 累计 3 篇新作答或距上次备份超过 7 天时温和提示导出；
   - 点击右上角 **【💾 导出全量备份】** 即可下载单个 `.json` 备份文件，换电脑一键导入复原。
