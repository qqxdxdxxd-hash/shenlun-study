# 0002. 默认 Skill 版权中立与用户自定义 Skill 生成机制

## Context
系统需要为考生提供高水平的批改服务。虽然很多高水平批改逻辑源自机构与名师教研成果，但在软件系统默认预置内容（Default Assets）中直接出现商业辅导机构或具体名师真实姓名，存在侵权与法律合规风险。同时，不同考生有各自追随的名师体系，需要能够自由上传自有讲义与资料。

## Decision
1. **默认预置 Skill 去品牌化与角色化**：
   - 默认随系统分发的 Skill 严禁出现任何真实老师姓名与培训机构品牌；
   - 统一采用客观中立的公职阅卷专业角色命名（如“材料作文大五段规范专家”、“公文题三轨阅卷专家”、“考场前10秒盲审考官”）。
2. **开放用户自定义 Skill 生成器（Skill Maker）**：
   - 允许考生自行上传本地学习资料（PDF/Markdown/TXT 笔记与讲义）；
   - 系统提供 Skill 自动生成器，提取其阅卷逻辑、赋分权重与 Prompt 规范，生成存储在考生本地的私有 Skill，此部分完全由考生自主命名与管理，不受版权限制。
3. **支持批改模式自由切换**：
   - 考生可自由选择“单 Skill 快速批改”，或选择“多 Agent 独立对话打分后综合评定”。

## Consequences
- **优势**：消除了产品发布与分发的法律合规风险；同时通过“资料上传生成 Skill”赋予系统无限可扩展性。
- **代价**：需要实现一个将用户上传文本自动转化为标准 `SKILL.md`（含 frontmatter 与评分规则）的轻量提炼流程。
