## 三、 系统技术架构与关键规范 (Architecture)

### 3.1 本地浏览器存储中枢 (IndexedDB Schema)
数据库名：`ShenlunStudyDB`（Version: 2）：
1. `memories`：个人名言、特色对策与避坑错题卡（含 SM-2 调度字段 `repetitions, interval, ease, nextReview`）；
2. `submissions`：考生历史作答记录；
3. `reports`：完整色谱跨距、量化四维得分表、多视角判语及标杆重写示范；
4. `dossier`：跨试卷认知病灶档案（记录 `ERR_COPY_OVER_20`, `ERR_COLLOQUIAL`, `ERR_STRUCTURE_DEFECT` 等）；
5. `custom_skills`：考生在提炼工坊中自建的私有批改专家；
6. `private_kb`：考生上传的私密 PDF 提取文本、时政材料与个人笔记。

### 3.2 无状态算力后端架构 (FastAPI Engine)
1. **纯无状态设计**：服务器不配置数据库，不存储任何考生答卷与个人资产；
2. **严格 BYOK 密钥管理**：API Key 保存在考生本地浏览器，发起请求时透传，服务端仅在内存中转发，用完即焚；
3. **PyMuPDF 内存流解析**：`POST /api/extract-pdf` 在内存流中直接提取 PDF 的文字图层，毫秒级响应，零磁盘文件落地；
4. **子串引用锚定定位器 (SpanResolver)**：大模型仅输出字面引用原句，本地 Python 执行子串匹配与正则模糊对齐，计算精确 `[start, end]` 物理坐标；
5. **本地确定性抄袭红线预检**：本地运行 15 字符滑动窗口比对给定材料与作答文本，精准核算连续抄袭字数与全局抄袭率。

### 3.3 题型解耦与数据通讯契约 (Skill-Decoupled Protocol)
1. **通讯契约扩展**：
   - `ReviewRequest`：支持前端传递 `target_score`（分值）与 `word_limit`（字数限制）；若未传，则为 `None` 由大模型从材料中提取；
   - `ReviewResponse`：必须返回大模型或系统解析确认的 `target_score`（浮点/整型）与 `word_limit`（可选整型），实现前后端数据闭环。
2. **系统代码零硬编码铁律**：
   - 严禁在系统代码层（`mar_rewriter.py` / `evaluator.py` / `local_drill.js` / `api_client.js`）拼装固定的“1000~1100字”、“1+3大五段”等排他性结构要求；
   - 阅卷定档逻辑、扣分阶梯、重构范本形态由对应题型的 `SKILL.md` 全权定义，系统代码只负责参数透传与结果渲染。
3. **单一题纯净材料流规范 (Pure Material Stream Principle)**：
   - **RAG 隔离**：单一题（`qType === 'single'`）在提交批改时，系统代码严格阻断 `MiniRAG` 调用，`recalled_memories` 强制传空数组 `[]`；
   - **去除强行标签**：严禁在单一题 Prompt 中要求大模型标注 `[来自记忆库: xxx]`；
   - **考场真实度**：单一题标杆示范重写必须忠实于材料原文实词，严禁生造晦涩专业词汇、脱离材料过度抽象概括或堆砌外部政治上位词；
   - **字数红线卡位**：范文重写严格卡位在题目限定字数以内（如 250 字内），离线 Fallback 模式亦输出条理性小题要点范本。
4. **分值与字数智能解析与动态渲染规范**：
   - **智能提取**：系统自动通过正则对题干与要求文本进行自适应提取：
     - 分值提取正则：`/(?:满分|分值|共计?|总分)\s*[:：]?\s*(\d+(?:\.\d+)?)\s*分|[（(]\s*(\d+(?:\.\d+)?)\s*分\s*[)）]/`
     - 字数限制正则：`/(?:不超过|限|以内|至多)\s*(\d+)\s*字|(\d+)\s*字以内/`
   - **界面显式渲染**：主评分框呈现为 `${res.score} / ${effectiveTargetScore}分`，副标题呈现真实得分率 `${(res.score / effectiveTargetScore) * 100}%`；
   - **四维量化得分自适应**：四维量化得分明细表（`QuestionTypeRubrics.getDimensions`）以实际 `target_score` 动态等比计算各细分维度的满分值。
