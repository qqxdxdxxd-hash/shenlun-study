# 申论公文题三轨专业阅卷专家（shenlun-official-doc）

本标准依据公务员考试与事业单位统考《贯彻执行/公文写作》官方阅卷**“格式分 + 内容分 + 语言逻辑分”三轨模型**建立。适用于汇报提纲、工作指南、宣传展板文稿、谈话提纲、发言提纲、公开信、倡议书等一切贯彻执行题型。

---

## 1. 考场三轨给分模型（以主流 20～25 分题为基准）

$$\text{公文实得分} = \text{格式分（2～4分）} + \text{内容采分点（14～16分）} + \text{语言与结构分（2～3分）} - \text{扣分项}$$

1. **格式分（2～4分）**：
   - 标题：公式完整、居中独占一行、**严禁加《》书名号**（加书名号直接扣 1～2 分）；
   - 主送称谓与落款：依据文种性质严格取舍。
2. **内容分（14～16分）**：
   - 以给定资料的原词原意为采分点，踩点给分，宁多勿少；
   - 必须采用**“前置动宾短语小标题 + 支撑实词展开”**结构。
3. **语言与结构分（2～3分）**：
   - 结构脉络符合法定行政逻辑（发文缘由 ➔ 现状/问题 ➔ 举措/对策）；
   - 角色代入精准，语体口吻符合机关上行、平行或监管场景。

---

## 2. 格式三件套取舍决策树

- **【完整公文类】（公开信、倡议书、通知、通报）**：
  - **五要素齐全**：标题（居中无书名号） + 主送称谓（顶格冒号） + 正文发文缘由 + 主体分条 + 发文机关与日期（右下角两行）。
- **【提纲/规程/展示类】（汇报提纲、工作指南、宣传展板、谈话提纲、发言提纲）**：
  - **仅保留标题，严禁写称谓与落款**；
  - 提纲类文种盲目添加称谓或右下角落款，**倒扣 1 分格式分**。

---

## 3. 五大类核心公文行文骨架

1. **汇报提纲类（上行汇报）**：
   - 一、基本情况与调研/整治背景（发文缘由）
   - 二、主要成效与存在问题（痛点剖析）
   - 三、下步工作思路与深化建议（对策重心）
2. **工作指南类（操作规范）**：
   - 前言（极简，写明制定依据与目的） ➔ 主体按要素分项巡查（消防安全、燃气用电、食品卫生、经营秩序） ➔ 处置流程与纪律要求。
3. **宣传展板类（对外展示）**：
   - 导言（简介与宗旨） ➔ 前世篇（历史渊源与原貌） ➔ 今生篇（空间改造与业态焕新） ➔ 结语（文旅邀请与展望）。
4. **面对面谈话提纲类（监管指导）**：
   - 一、肯定成绩（奠定合作基调） ➔ 二、严肃指出问题与隐患（摆事实依据） ➔ 三、提出限期整改要求与推进时限。
5. **典型案例推荐要点类（申报推荐）**：
   - 推荐理由与背景 ➔ 核心治理经验与创新做法 ➔ 取得的治理成效与推广价值。

---

## 4. 机关身份场景口吻与语病红线

1. **场景口吻四分法**：
   - 上行汇报：客气谦逊、求真务实、条理分明；
   - 监管谈话：严肃严肃、有礼有节、严慈相济、整改闭环；
   - 工作指南：指令具体、操作性强、责任清晰、动宾引领；
   - 对外宣传：通俗生动、真挚典雅、富于文旅感召力。
2. **考场四大语病扣分红线**：
   - ❌ `广大市民朋友们`（“广大”与“们”重复，语义病句，扣分）；
   - ❌ `彻底根治/完全杜绝`（极端化夸大用词，违背行政客观实际，扣分）；
   - ❌ 通篇口语大白话流水账（未提纯政务动宾大词，扣分）；
   - ❌ 基层人员向全国人大越权建言（身份越权口吻错位，扣分）。
