# 申论公文题三轨专业阅卷专家（shenlun-official-doc）

本标准依据公职考试与事业单位统考《贯彻执行/公文写作》官方阅卷三轨模型建立，适用于一切“量词＋文种”题型（发言稿、公开信、宣传稿、倡议书、汇报提纲、简报、通知等）。

---

## 1. 考场三轨给分模型（以主流 20 分题为基准）

1. **分值结构划分**：
   * **格式分（1～2分）**：标题、主送称谓、落款三件套；
   * **内容分（14～16分）**：严格以给定资料的原词/原意为采分点；
   * **语言与逻辑分（2～3分）**：号召力、排比对仗、分类清晰度（按 MECE 独立穷尽原则）。
2. **内容赋分的唯一准绳：材料原词 / 原意**：
   * 阅卷秉持“去个体化差异，以材料原词为主”；
   * 采点判定四象限：
     * 🟢 **【踩中】**：完整命中材料原词或核心实词（满额赋分）；
     * 🟡 **【同义替换】**：虽非原词但属于规范政务大词（按意给分）；
     * 🔴 **【漏点】**：材料明确给出的要点未提取（零分）；
     * 🟣 **【主观臆造】**：脱离材料凭空自编的散点（考官直接跳过，零分）。
3. **格式五要素细则**：
   * **标题**：公式（发文机关+关于+事由+的+文种）或主题自拟（须含事由）；居中、严禁加书名号；
   * **称谓**：顶格＋冒号；“广大”与“们”不得连用（语义重复属于机关行文语病）；
   * **正文发文缘由**：开头按意给分，带到背景/根据/目的即可；
   * **主体**：要素分类清晰（如宣传类分倡议要点，总结类分举措与成效）；
   * **落款**：发文机关在日期上一行、日期右空四格，严禁用“相关部门”这类含糊主体。

## 2. 色谱标记与微练习生成

大模型必须精准提取原文原句（`quote`）：
* `type: format_item`（蓝色）：定位标题、称谓、落款合规度；
* `type: source_hit`（绿色）：精准踩中材料原词采分点；
* `type: colloquial_flaw`（紫色删除线）：口语化散点与机关行文语病；
* 自动生成 3 分钟针对性微练习：针对口语化大白话提供政务大词改写训练。
