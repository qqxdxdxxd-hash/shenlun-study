# 申论公文题格式三件套取舍与标题称谓落款决策树
（Official Document Format Decision Tree: Title, Salutation & Inscription）

## 1. 核心阅卷心智与格式分权重

在国家与各省公务员考试中，公文题/贯彻执行题的满分通常为 **20～25 分**，其中：
- **格式分**：固定占 **2～4 分**（标题 1～2 分，主送称谓与落款 1～2 分）；
- **内容分**：占 **14～16 分**；
- **语言与结构分**：占 **2～3 分**。

考官初扫试卷的前 3 秒，首先核验**“版面格式是否规范”**。格式写对，保底拿满 3～4 分；格式写错（如盲目添加书名号、提纲题生搬硬套落款），考官第一印象直接定档为“不熟悉机关公文基本规程”，可能连带扣减形式分。

## 2. 格式三件套取舍终极决策树

考场中最常见失分点是**“该写格式的不写，不该写格式的乱写”**。按公文文种性质建立以下绝对决策树：

```
                    公文文种格式取舍判断树
                              │
         ┌────────────────────┴────────────────────┐
         ▼                                         ▼
   【完整公文类】                             【提纲/规程/展示类】
公开信、倡议书、宣传稿、                   各类提纲（汇报提纲/发言提纲/谈话提纲）、
通知、通报、通告、致辞                      工作指南、工作要点、宣传展板、调查报告
         │                                         │
         ▼                                         ▼
【五要素齐全三件套】                      【仅保留标题，去称谓与落款】
1. 标题（居中，严禁书名号）               1. 标题（居中，严禁书名号）
2. 主送称谓（顶格冒号）                   2. 严禁写主送称谓（直接入正文）
3. 正文发文缘由                           3. 严禁写落款与日期
4. 正文主体措施                           4. 正文分条列项推进
5. 发文机关与日期（右下角）
```

| :--- | :--- | :---: | :---: | :---: | :---: | :---: | :--- |

## 3. 标题拟定公式与四大避坑铁律

### 1. 标准通用公式
$$\text{公文标题} = \text{发文机关/调研主体} + \text{关于} + \text{事由} + \text{的} + \text{文种}$$
- **范例 1（汇报提纲）**：`D市语言文字规范化联合整治工作组关于实施整治工作思路的汇报提纲`
- **范例 2（座谈会发言）**：`在促进“无人经济”新业态健康发展座谈会上的发言提纲`
- **范例 3（安全巡查指南）**：`大帆夜市平安夜市安全巡查工作指南`
- **范例 4（调研汇报）**：`关于某街道基层治理调研情况与改进建议的汇报提纲`

### 2. 展板与宣传类标题（双标题法）
- `主标题（文雅凝练/对仗） + 副标题（破折号引出事由文种）`
  - 示例：`唤醒沉睡粮仓  筑就文旅新篇 —— 今州粮仓“前世今生”宣传展板文稿`
- 亦可直接采用政务单标题：`今州粮仓“前世今生”宣传展板文稿`

### 3. 考场标题四大扣分红线
1. **严禁加《》书名号**：公文试卷中标题加书名号（如《关于……的汇报提纲》），**直接扣 1～2 分**！
2. **位置居中独占一行**：顶格或未居中扣 0.5 分；末尾严禁加句号等标点。
3. **字数过长折行规则**：若标题超过一行（>25 字），按语义在虚词处断开，第二行居中对齐，排成“倒梯形”或“菱形”。
4. **事由必须精准切题**：不得漏掉核心事由（如只写《汇报提纲》判半准或零分）。

## 4. 主送称谓与落款规范

### 1. 称谓规范（适用对外公开信/倡议书/会议致辞）
- **顶格书写**，后跟中文全角冒号`：`；
- **机关语病禁忌**：
  - ❌ `广大市民朋友们：`（“广大”与“们”语义重叠，机关公文语病，扣分）；
  - ✅ `广大市民朋友：` 或 `市民朋友们：`；
  - ✅ `各有关单位、广大居民：`；
  - ✅ `尊敬的各位领导、与会代表：`。

### 2. 落款与成文日期规范（适用公开信/倡议书/通知）
- **发文机关在上一行，成文日期在下一行**；
- 靠右对齐（日期末尾右空两格或四格）；
- **严禁用“相关部门/某单位”**：必须根据题干身份明确署名（如“向阳街道办事处”、“S县政府办公室”）；
- **日期规范**：写当前考试年月日（如“2025年10月29日”）或“XX年XX月XX日”。
