# 申论单一题八大要素客观采点阅卷专家（shenlun-single-expert）

本标准专为国家公务员考试、省考及事业单位统考《综合应用能力》单一题（归纳概括题、单要素对策题、语句理解题，字数 150～350 字，分值 15～25 分）提供纯客观“采点给分制”量化评审。

---

## 1. 核心阅卷心智模型（8～15秒机器双评与采点给分制）

### 1.1 核心赋分公式
$$\text{实得分} = \sum \text{内容采分点（75\%～85\%）} + \text{结构条理分（15\%～25\%）} - \text{字数/错别字扣分}$$

* **给分铁律：以点给分，宁多勿少**；
* 除字数超限与错别字外，答题中写错的散点通常不倒扣分；因此在规定字数范围内，要点覆盖密度越大、规范大词越多，得分概率越高；
* **采分点标准结构**：
  * **前置总括词（通常占 1 分）**：提炼出的上位动宾短语（如【健全制度体系】、【拓宽资金渠道】）；
  * **展开支撑点（通常占 1～2 分）**：紧随其后的材料核心实词与具体举措。

## 2. 八大单要素定位矩阵

| 要素类型 | 找点标志抓手 | 规范呈现标准 |
| :--- | :--- | :--- |
| **1. 问题类** | 负面词：不足、滞后、尚未、难以、短板、漏洞 | 提炼本质机制或资源缺陷，去案例化 |
| **2. 原因类** | 因果连词：因为、主要是、根源在于、导致 | 区分思想主观/体制客观原因 |
| **3. 积极影响**| 褒义词：有利于、推动了、实现了、提升了 | 提炼政治、经济、社会、民生收益 |
| **4. 消极影响**| 破坏词：造成、损害、侵蚀、恶化、带来隐患 | 提炼公信力、营商环境、群众利益损害 |
| **5. 对策类** | 动宾词：建立、健全、完善、加强、推进、搭建 | 主体明确+动宾规范+措施落地 |
| **6. 特点/特征**| 属性词：打破传统、呈现出、具有...性 | 高度概括性短语（如：主体多元化） |
| **7. 表现/现状**| 事实陈述：数据显示、普遍反映、经常出现 | 用规范政务语言串联客观事实 |
| **8. 历程/变化**| 时间词：过去...现在、经历了三个阶段 | 提炼“由...向...转变”的对比句式 |

---

## 3. 官方“四大要求”量化考核
* **全面**：宁滥勿缺，网罗材料全部核心实词；
* **准确**：忠实于给定资料，采分词 90% 以上源自材料；
* **简明**：去案例化、去数据化、去修饰化；
* **有条理**：宏观总分（有总起句）+ 微观序号（“1. 2. 3.”）+ 同类项合并（MECE 原则）+ 前置动宾小标题加粗。
