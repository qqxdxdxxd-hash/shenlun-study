# 申论单一题采分点大词化与同义替换速查词典
（Lexicon Distillation, Synonym Equivalence & Inferred Countermeasures Handbook）

## 1. 采分点“大词化”提纯算法与上位公式

申论采点阅卷中，考官只认**“符合政务话语体系的规范表达”**。
考生如果原封不动抄录材料中的群众口语、案例流水账或具体数字，通常只能拿 0.5 分的勉强同义分，甚至直接漏判；而一旦提炼为上位政务动宾短语，即可直接锁定满分采分点。

### 1.1 大词提纯三步法
$$\text{大词提炼} = \text{动作规范化（高频政务动词）} + \text{对象客体抽象化（政务名词）} + \text{成效支撑落地}$$

* **第一步：剔除枝节**。去掉特定人名、企业名、微观数额（如把“张某投入200万买设备”中的“张某”、“200万”剔除）；
* **第二步：动词上位**。将口语化动作（“到处找钱”、“找大学生来干活”、“用手机看河道”）替换为政务动词（“拓宽融资渠道”、“强化人才保障”、“推进数字化监测”）；
* **第三步：宾语聚合**。将具体物件（“大棚、水渠、桥洞、泥巴路”）聚合为上位规范领域（“农业基础设施”）。

## 4. 针对问题“反推对策”合理性给分判定边界
（Inferred Countermeasures Boundary）

在 2024地市第4题（数据标注）、2022执法第3题（小李两难）、2020地市第4题（农家乐重启）等题目中，官方评分参考均带有明确声明：
> **“注：针对材料中的问题，考生自己提出的解决措施，只要切实可行、合理即可给分。”**

### 4.1 允许反推的前提条件
1. 题干明确要求提出“建议/对策/措施/解决路径”；
2. 材料中通篇罗列的是痛点、短板、困境、矛盾，未直接给出成型的做法。

### 4.2 “合理给分”的三大刚性标尺（判定给分依据）
* **标尺 1：主体明确（Who does it）**
  - 合格：明确由“政府市场监管部门”、“行业协会”、“企业主体”或“村集体”负责；
  - 违规：无主语的抽象祈使句。
* **标尺 2：靶向对应材料痛点（Problem-Solution Mapping）**
  - 材料问题：“缺少先进设备，检测技术落后” $\rightarrow$ **给分措施**：“争取财政资金购置先进勘测设备，引进第三方专业评估机构”；
  - 材料问题：“人员老龄化严重，缺乏年轻人” $\rightarrow$ **给分措施**：“提高薪酬福利，与高校建立定向委培机制，招聘专业应届生”；
  - 材料问题：“农家乐同质化严重，缺少特色” $\rightarrow$ **给分措施**：“挖掘本土非遗与乡村特色文化，打造沉浸式特色农旅IP”。
* **标尺 3：政务可行性（Feasibility & Common Sense）**
  - 符合我国法律法规与政府职能常识；措施具备可落地动作（动宾短语），非空洞套话。

### 4.3 判定为 0 分的反推“四大雷区”（Anti-Patterns）
1. **假大空口号**：仅写“提高思想认识”、“加强宣传教育”、“强化责任担当”而无具体落地手段；
2. **靶向错位**：材料反映的是“资金短缺”，考生作答“加强网络舆情监控”；
3. **越权或违背常识**：建议由乡镇科员直接修改国家法律、或要求政府无底线包办企业商业风险；
4. **同义反复堆砌**：将同一个措施用不同的词分写为 3 条（如第1条写“增加钱款投入”，第2条写“多给点资金”，第3条写“财政给预算”），仅按 1 点给分。
