# 申论单一题材料逐段寻点与正反过滤实战手册
（Material Hunting & Noise Filtering Heuristics）

## 1. 核心定位与阅卷心智

单一题作答的本质是**“在有限格子内做信息密度最大化的信息检索与政务大词提纯”**。
真实考场中，给定材料通常有 5～12 个自然段（约 1500～3000 字），但作答字数往往被严厉限制在 200～350 字以内。如果考生“见字就抄、段段摘录”，必然导致核心采分点拥挤爆仓、后半程关键要点直接漏失。

名师评卷核心法则：**“宁留骨架，不带泥沙；凡背景必略，凡案例必剥，凡观点必提，凡总结分流。”**

## 2. 材料段落“四分法”模型与过滤引擎

| 段落类型 | 典型行文标志 | 考场价值属性 | 提炼与过滤法则 |
| :--- | :--- | :--- | :--- |
| **1. 背景引入段** | “近年来……”、“长期以来……”、历史渊源描摹、清澈河水/车水马龙画面描写 | **无分废段（90%略读）** | **直接跳读过滤**。不占用答题字数。特例：除非段中直接给出官方界定的“制度定义”或“唯一例外属性”（如宣化“唯一发源于城市由城向郊发展的系统”）。 |
| **2. 典型案例段** | 出现具体人名（“张某某”、“李老汉”）、具体投资额（“投入200万元”）、企业内部琐事、农技过程 | **高价值矿石段（须深度去粗取精）** | **“剥洋葱”三步提炼法**：<br>1. 剔除人名/地名/企业名 -> 抽象为“经营主体/主管部门/专业人才”；<br>2. 剔除具体数字/琐碎步骤 -> 抽象为规范政务行为；<br>3. 提取动宾核心实词。 |
| **3. 专家/干部/群众观点段** | “专家指出……”、“有关负责人表示……”、“村民纷纷抱怨……” | **纯金富矿段（采分词聚集地）** | **原词锁定与上位转化**：往往直接包含政策大词、问题痛点或对策方向，优先摘取或稍作规范化微调即可作为采分点。 |
| **4. 总结与展望段** | “总的来看……”、“下一步，该市将继续……”、“形成了……格局” | **分流判断段** | **视题干时态与任务决定存废**：<br>- 题干问“已取得的成效/做法”，尾段“下一步打算”一律作为废话剔除；<br>- 题干问“未来发展建议/对策”，尾段规划即为直接答案源。 |

## 3. 常见废段与噪音过滤三大“反模式”

### 3.1 宏观背景与抒情渲染过滤（Background Stripping）
* **真题典型**：2025地市第2题（治水良性互动）第1段：“清澈的万龙河水两岸，杨柳依依，秀丽如画，市民三三两两在步道散步……”
* **名师判定**：这是典型的情境描写与案例铺垫，没有任何政府与企业的互动做法，**1分不值，一个字也不要抄**。
* **诊断法则**：凡是文学性修饰、天气与环境描述，直接划掉。

### 3.2 案例枝节与微观数据过滤（Case Details Stripping）
* **真题典型**：2025地市第1题（宣化葡萄园生态智慧）：“张老汉在漏斗架下搭设了3个小竹亭，投入5000元买来农家肥，施用在龙眼葡萄根部……”
* **名师判定**：不能写“张老汉搭建小竹亭、投入5000元”，必须提炼为：“采用漏斗架形式，利用活动空间；使用绿色环保材料与农家肥”。
* **诊断法则**：将具体的“人名、地名、具体数额、动植物名”全部替换为政务范畴词汇。

### 3.3 尾段总结套话过滤（Tail Summary Stripping）
* **真题典型**：2024地市第4题（数据标注企业）尾段：“展望未来，清溪县将继续高举创新大旗，以数字化赋能县域经济腾飞……”
* **名师判定**：这是常见的会议报告结语，无具体措施，属于虚词，一律过滤。

## 5. AI 批改判卷应用指南（五维诊断对照）

当在批改考生答案时，比对本手册规则执行诊断：
1. **废段误采诊断**：如果考生摘抄了“杨柳依依”、“车水马龙”、“下一步打算”，批注：
   > `【无效信息冗余】摘抄了材料第X段背景描写/无分展望，挤占有效采分空间，建议直接跳读剔除。`
2. **案例化未抽象诊断**：如果考生保留了具体人名“张某某”、具体金额“5000元”，批注：
   > `【案例语言未抽象】作答停留在事实陈述层面，需剥离人名与微观数字，提炼为规范政务动宾短语。`
3. **关键采分段漏点诊断**：如果考生漏掉专家观点段或转折连词后的核心名词，批注：
   > `【核心采分段遗漏】未能识别材料第X段转折词“然而/重点在于”后的核心机制，导致失分。`
